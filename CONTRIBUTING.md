# Contributing to battery-passport-after-first-life

Thanks for your interest in this project.

## Project description

The repository holds a proposal to amend the Catena-X standard CX-0160 (Battery Passport) for the battery's life after
its first passport, and a reference implementation of the proposed interfaces. The content is prepared as a
contribution to Eclipse Tractus-X: <https://projects.eclipse.org/projects/automotive.tractusx>

## How to contribute

* Open an issue that describes the change before you open a pull request.
* Every requirement change starts in the requirements registry in `requirements/`. A code change cites the
  requirement that it implements.
* Every file carries the license header of its kind, as TRG 7.02 of the Tractus-X Release Guidelines describes it.
  Every documentation file ends with a NOTICE section, as TRG 7.07 describes it.
* Commit messages follow the Conventional Commits format.

## Eclipse Contributor Agreement

The content of this repository is prepared as a contribution to an Eclipse Foundation project. A contributor to an
Eclipse Foundation project must electronically sign the Eclipse Contributor Agreement (ECA).

* http://www.eclipse.org/legal/ECA.php

Please sign the ECA with the email address of the "Author" field of your Git commits before you contribute here, so
that your contribution can move to Eclipse Tractus-X.
